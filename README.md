# Group 28 - Recipe & Smart Meal Planner

## Project

Recipe & Smart Meal Planner is a Python-based Streamlit web application.

The application allows users to:

- Search for recipes
- Plan meals
- Manage ingredients
- Generate shopping lists
- Scale recipe servings
- Save and export meal plans
